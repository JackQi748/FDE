# 11 · 迭代增补（2026）

> 本目录是 JackQi748 在上游 [VanGong1999/FDE](https://github.com/VanGong1999/FDE) 基础上**自行增补**的部分：聚焦「能直接上手跑起来」的工程内容，补上游偏方法论/面试视角的不足。
> 上游负责体系与广度，本目录负责落地与时效。两个目录互补，不重复。

## 为什么要这一节

上游 00–10 已经把「FDE 是什么、怎么交付、怎么面试、概念怎么讲」讲得很全。但落到 **2026 年的真实现场**，还差三块：

1. **时效**：模型、平台、协议每半年一变，需要一份持续更新的「当下格局」。
2. **部署**：RAG/Agent 方案选定后，「怎么把模型真正跑起来、跑便宜、跑稳」几乎没人手把手讲。
3. **可量化**：把「效果好不好」从体感变成可重复的评测脚本。
