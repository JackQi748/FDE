# 企业网络与私有连接白话

客户常说：「数据不能出网 / 要专线 / 要私有化」。本篇帮助 FDE **把模糊合规语言翻译成可选项**，并与云/网络/安全工程师协作——目标不是考网络证书，而是**问对问题、画对图、推动书面决策**。

相关：[企业 SSO 与权限](./企业SSO与权限模型.md)、[气隙与战术边缘](./气隙与战术边缘部署.md)、[架构决策树](../03-AI落地/架构决策树.md)、[GCP 云架构](./GCP云架构与基础设施.md)。

## 1. 先拆开「不能出」三个意思

同一句话背后可能是完全不同的方案：

| 客户说的「不能出」 | 真实含义 | 常见技术/合同手段 |
|--------------------|----------|-------------------|
| 流量不走公共 Internet | 链路隔离 | VPC、私有链路、专线、专有区域 |
| 数据不能被模型商训练/留存 | 数据处理条款 | 零数据保留、企业合约、专有端点 |
| 数据不能离开某国/某机房 | 驻留与主权 | 区域锁定、本地部署、气隙 |

**发现阶段必问清哪一种（或几种叠加）**，再谈架构。写进决策备忘录，避免口头误解。

## 2. 常见要求与对应手段

| 客户说的话 | 可能真实需求 | 常见手段 | FDE 注意 |
|------------|--------------|----------|----------|
| 不能出公网 | 流量不经公共 Internet | VPC 内资源、Private Link、专线 | 模型推理放哪要单独画 |
| 不能给第三方 | 禁止外部模型商或禁止训练 | 本地/专有模型，或合同+技术控制 | 「第三方」含日志与标注外包吗？ |
| 固定出口 | 防火墙白名单 | NAT 固定 IP / 出口网关 | 要运维配合申请与变更窗口 |
| 要专有云 | 强隔离 | 厂商专有区域/私有化套件 | 版本滞后与补丁责任写清 |
| 要审计一切 | 可追溯 | 集中日志、不可篡改存储、工单号串联 | 提示词里是否含 PII？ |
| 要专线 | 稳定低时延或合规 | Interconnect / ExpressRoute 等 | 周期常以周计，别承诺下周 |

## 3. AI 应用典型拓扑

```text
用户 → 企业SSO → AI应用(VPC)
              → 向量库/DB(VPC)
              → 工具/业务API(VPC或私有链路)
              → 模型推理（三选一，写进设计）：
                    A) 同VPC/机房私有模型
                    B) 经私有链路到厂商专有端点
                    C) 受控出站到公有API（合同+DLP+固定出口）
```

### 设计文档里至少标注

1. 选中的推理路径（A/B/C）  
2. 数据驻留区域  
3. 日志落点与保留期  
4. 密钥与 KMS 位置  
5. 故障降级是否仍符合驻留（例如降级到「仅检索不生成」）

## 4. 和网络/安全开会时怎么问

把会开成「选项会」而不是「被否决会」：

1. 哪类数据允许出站到模型商？抽样举 3 个字段  
2. 出站是禁止，还是允许但需 DLP/脱敏？  
3. DNS 与镜像源是否必须内网？  
4. 是否已有 Private Link / 专线预算与工单？  
5. 证书与PKI由谁签发？  
6. 生产变更窗口与回滚要求？  

输出：**一页拓扑 + 开放问题列表 + 需要谁拍板**。

## 6. 与「私有化」决策

走 [架构决策树](../03-AI落地/架构决策树.md)：

许多合规可通过 **RAG + 网关 + 日志管控 + 企业合同 + 区域锁定** 满足，不必一上来私有化全家桶。

| 方案 | 优点 | 代价 |
|------|------|------|
| 公有 API + 强合同/网关 | 快、模型新 | 出站与法务谈判 |
| 专有端点 / VPC 对接 | 平衡 | 厂商与网络依赖 |
| 本地/私有模型 | 驻留强 | 运维、硬件、效果与版本 |
| 气隙 | 最强隔离 | 投递与同步极重，见气隙专篇 |

**书面权衡**：成本、时效、效果、运维归属、升级频率——让赞助人选题，而不是工程默默扛最重方案。

## 7. 迷你情景练习

**情景**：客户说「数据不能出网，但要用你们最强的云端模型，下周 Demo」。

**参考拆法**：

1. 澄清「不能出」指链路还是训练还是出境  
2. 若只要「不训练」→ 谈企业端点与合同，画受控出站  
3. 若真禁止任何出站 → 本地模型或把 Demo 范围缩到脱敏样例 + 诚实说明差距  
4. 拒绝「既气隙又云端最强又下周」的不可能三角，给选项备忘录
