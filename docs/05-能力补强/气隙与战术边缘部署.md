# 气隙与战术边缘部署

> 整理并扩展自 Awesome FDE「Air-Gapped & Tactical Edge」。  
> 最难的前线工作发生在互联网到不了的地方：保密隔间、舰艇、前线基地、离线产线、强监管本地飞地。标准云剧本失效——你必须**把平台运进去**。

相关：[企业网络白话](./企业网络与私有连接白话.md)、[GCP 架构](./GCP云架构与基础设施.md)、[生产化清单](../03-AI落地/生产化清单.md)。

---

## 1. 何时你真的在做气隙 / 边缘

| 信号 | 含义 |
|------|------|
| 主机不能访问公网包源 | 必须内网镜像 |
| 模型权重不能经 Internet 拉取 | 物理投递 + 校验 |
| 跨密级传输要审批 | CDS / 二极管周期以月计 |
| 「先 on-prem 随便跑跑」 | 可能是深层不信任云——写清约束 |

**发现第 1 周就要问清**：分级、认证路径、投递方式、谁签字。第 12 周才发现等于项目事故。

---

## 2. 合规基石（先于写代码）

| 概念 | 含义（简述） |
|------|----------------|
| **ATO** | 授权官允许系统在其网络运行；常走 NIST RMF，可能 6–18 个月 |
| **DoD Impact Levels** | IL2～IL6，决定云与网络飞地 |
| **FedRAMP** | 联邦民用；许多 GenAI 仅 Moderate——可能硬拦 |
| **STIG** | 加固清单；CI 产物不合规过不了 ATO |
| **ITAR / EAR** | 出口管制；权重本身可能受控 |
| **CMMC 2.0** | 国防承包商认证；实务常对齐 NIST SP 800-171 |

国内强监管/专网客户未必用这些缩写，但**等价问题**一样：谁授权、什么基线、如何审计、如何补丁。

---

## 3. 离线模型权重与包镜像

| 项 | 做法 |
|----|------|
| 权重 | 加密介质；SHA-256；优先 safetensors |
| 溯源 | 来源、许可证、训练数据证明 |
| 包镜像 | 内网 PyPI/npm/APT；禁公网 install |
| CVE | Trivy/Grype + 离线 NVD；准入前扫描 |

「我们从 HuggingFace 下的」——审计场合通常不是合格答案。

---

## 4. 加固容器与供应链

- 客户指定源（如 Iron Bank）优先  
- Harbor + Cosign 签名；Kyverno/OPA 拒签未签名镜像  
- distroless / chainguard 基座  
- SBOM 与可复现构建（按客户要求）  

---

## 5. 跨域与同步

| 模式 | 用途 |
|------|------|
| 数据二极管 | 物理单向（权重进 / 遥测出） |
| CDS | 跨密级；审批可能数月——发现期列入计划 |
| 清单制同步 | 签名清单 + 人工签核 + 审计；禁后台偷同步 |
| 出境 DLP | 清洗 PII/坐标/敏感关键词后再到低侧 |

---

## 6. 边缘运行时

| 组件 | 用途 |
|------|------|
| K3s / MicroK8s / k0s | 轻量可断网 K8s |
| Distributed Cloud / 裸金属发行版 | 机房内类托管 |
| Ollama / vLLM / llama.cpp / TensorRT-LLM | 本地推理 |
| Fluent Bit + 本地 WAL | 断网缓存，连通再发 |

**容量规划**：量化模型、上下文长度、并发——边缘硬件往往是瓶颈，而不是「再加一个 Agent」。

---

## 7. 气隙特有故障模式

| 故障 | 缓解 |
|------|------|
| 时钟漂移 | 第一天 Chrony/PTP |
| 证书轮换 | 飞地内 PKI |
| 密钥 | Vault+HSM 或 SOPS |
| 首次启动 | 签名 sneakernet ISO，Week 1 设计 |
| 补丁滞后 | 清单制补丁火车 + 窗口 |
| 「临时插网线」 | 书面禁止；违者审计 |

---

## 8. FDE 12 周节奏（示意）

| 阶段 | 焦点 |
|------|------|
| W1–2 | 分级、ATO/基线、投递路径、硬件清单 |
| W3–4 | 镜像与权重进场、校验、PKI/时间 |
| W5–8 | 应用部署、离线 Eval、红队 |
| W9–10 | 培训、Runbook、值班 |
| W11–12 | 门禁、签字材料、已知限制 |

网络与认证延迟不在你控制内——**排期要显式留缓冲**。
