# Snowflake 与 Databricks 现场精要

FDE 在数据平台型客户（或 Databricks 类雇主）常要在 **Lakehouse / 云数仓** 上交付，而不是只调 Chat API。本篇给你「能跟数据平台同事对话并完成试点」的实操深度。

相关：[数据工程基石](./数据工程基石课程.md)、[限域分析助手](../06-行业案例/06-限域数据分析助手.md)、[SSO 与权限](./企业SSO与权限模型.md)。

---

## 1. 你需要能解释的一张图

```mermaid
flowchart LR
  Src[业务系统/文件]
  Ingest[摄入与转换]
  Store[Warehouse或Lakehouse]
  Gov[治理与权限]
  Serve[BI_AI_特征]
  Src --> Ingest --> Store --> Gov --> Serve
```

| 层 | Snowflake 语境 | Databricks 语境 |
|----|----------------|-----------------|
| 存储计算 | 云数仓；虚拟 Warehouse 管算力 | Lakehouse；集群/SQL Warehouse/Serverless |
| 表格式 | 原生表 + 外部表等 | Delta Lake 等 |
| 治理 | Role、Row Access、脱敏 | Unity Catalog 等 |
| 作业 | Task/动态表/合作伙伴 ETL | Jobs/Workflows/dbt 等 |
| AI | Cortex 等（产品演进快） | Mosaic AI 等（产品演进快） |

产品名更新快——**以客户租户实测与官网为准**；本篇教稳定概念。

## 2. FDE 现场高频任务

| 任务 | 你交付什么 | 常见坑 |
|------|------------|--------|
| 探查 | 主题域地图、口径 owner、刷新与质量坑 | 听信「数仓里都有」 |
| 权限 | AI 用最小角色；行/列级可继承 | 服务账号万能 |
| 性能成本 | 避免全表扫；自动挂起；队列 | Demo 用了最大仓忘记关 |
| 为 AI 备数 | 语义层/宽表、PII、只读副本 | 直接打生产随意表 |
| 落地 | Eval 与日志落表可查 | 评测只在笔记本 |

## 3. 权限模型直觉（两边通用）

| 问题 | 好习惯 |
|------|--------|
| AI 服务用什么身份？ | 最小权限角色；按主题授权 |
| 用户差异可见性？ | 行级策略/安全视图；勿在应用层假装 |
| 训练/日志？ | 明确是否允许；隔离沙箱库 |
| 对外分享？ | 安全视图 + 审批；勿直接分享底层表 |
| 开发隔离？ | Dev/Test/Prod 分库或分 schema |

与 [SSO 专篇](./企业SSO与权限模型.md) 一起读：仓侧强制 + 应用侧身份传递。

## 4. 为 Text-to-SQL / 分析助手的平台清单

- [ ] 只读角色 + 表白名单  
- [ ] 查询超时与资源队列 / Warehouse 尺寸策略  
- [ ] 官方指标表或语义层存在且有 owner  
- [ ] 默认 `LIMIT`、禁止多语句  
- [ ] 成本归因标签（user/team）  
- [ ] 审计：谁跑了什么 SQL  
- [ ] 金标问题集（含易错口径）  

案例：[限域数据分析助手](../06-行业案例/06-限域数据分析助手.md)。

## 5. 成本与性能：FDE 要会说的话

| 现象 | 可能原因 | 动作 |
|------|----------|------|
| 账单暴涨 | 大仓常开、全表扫、重复刷新 | 自动挂起、分区裁剪、缓存结果 |
| 查询很慢 | 缺分区/聚簇、数据倾斜 | 与平台一起看查询画像 |
| AI 每次扫原始层 | 没建 Gold/语义层 | 先备数再接 LLM |

**演示纪律**：用小仓/小集群；结束即关；别用客户生产配额刷实验。

## 6. 两周自学微路径

| 天 | 动作 | 验收 |
|----|------|------|
| 1–2 | Quickstart：建库表、跑 SQL、看权限对象 | 能解释 Role/Catalog |
| 3–4 | 「每日销售」小模型 + 口径文档 | 有 README |
| 5–6 | 只读角色；第二用户验证不可见 | 截图或测试记录 |
| 7–8 | 定时作业刷新宽表 | 失败告警怎么做写清楚 |
| 9–10 | 20 条业务问题 → 金标 SQL | 含 3 道易错口径 |
| 11–14 | 最小 NL→SQL Demo + 护栏 | 白名单、LIMIT、只读 |

## 7. 与客户开会时的好问题

1. 数据的「单一真相」在哪张表/哪个域？  
2. 刷新 SLA？迟到时业务怎么办？  
3. 行级权限今天如何实现？AI 能否复用？  
4. 谁为指标口径签字？  
5. Dev/Test/Prod 如何隔离？  
6. 月度计算账单谁买单、如何告警？  
7. 是否允许把查询日志用于改进 AI？  

---

## 8. 反模式

- 给 AI 用 `ACCOUNTADMIN` / 工作区管理员  
- 无语义层直接 Text-to-SQL 打全库  
- 在生产仓跑探索性全表 `SELECT *`  
- 口径只在聊天里，不在文档/指标表  
- 把客户数据同步到个人账号做实验

## 9. 面试怎么讲

弱：「我用过 Snowflake。」  

强：「我在仓上为 X 主题建了只读语义层与 20 条金标 SQL；助手仅白名单；成本按团队归因；行级策略与平台同事联审后通过试点门禁。」
