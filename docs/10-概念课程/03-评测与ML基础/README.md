# 03 · 评测与 ML 基础

面向 FDE 交付与面试的概念轨道：把「看起来不错」变成可度量、可回归、可解释的判断。内容为原创中文讲解，侧重直觉、取舍与现场用法；可与 `docs/03-AI落地`、`docs/02-交付方法论`、`docs/05-能力补强` 交叉阅读。

## 怎么读

1. 先读 **06 金标数据集**、**12 离线vs在线评测**、**08 LLM-as-Judge**——这是交付门禁的三角。
2. 需要向客户解释指标时，补 **02 精确率召回率F1**、**07 校准**、**09 评测RAG**、**24 忠实度vs相关性**。
3. 涉及训练/微调决策时，再读优化与泛化一组（03–05、15–22）。
4. 上线实验设计看 **10 AB/金丝雀/影子**、**11 Bandits**、**13 合成数据**、**14 Benchmark 局限**。
