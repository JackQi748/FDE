# 梯度下降与学习率

## 直觉

损失函数是山谷地形图，参数是你站的位置，**梯度**指出最陡上坡，你反方向迈步就是下降。**学习率**是步长：太大则来回蹦、甚至发散；太小则走得像爬行，还可能卡在平台。

现代训练几乎都是**小批量随机梯度（SGD/Adam 系）**：用一批样本估计梯度，噪声反而有助于逃离尖銳差局部。

## 讲解

### 更新式

\[\theta \leftarrow \theta - \eta \nabla_\theta L\]

- \(\eta\)：学习率
- 动量：带着速度，减少震荡
- Adam：自适应每维步长，对稀疏梯度友好，但泛化有时不如精心调的 SGD

### 调度

常见：warmup（先由小到大，稳定大模型训练）→ cosine/线性衰减。微调 LLM 时学习率常比预训练低 1–2 个数量级；LoRA 可略高。

### 诊断信号

| 现象 | 可能原因 | 试法 |
|------|----------|------|
| loss 变 NaN | 步长过大/数值不稳 | 降 lr、裁剪梯度 |
| loss 平台 | lr 过小或数据不足 | 升 lr 或查数据 |
| train↓ val↑ | 过拟合 | 早停/正则 |
| 批次间剧烈抖 | batch 太小 | 增大 batch 或累积 |

## 工作示例

现场微调分类头：冻结骨干，只训最后一层。

1. 用 3 个 lr：1e-3 / 1e-4 / 1e-5 各跑 1 epoch 烟测
2. 看训练 CE 与验证 F1，而非只看 train loss
3. 选验证最好者，再跑完整 epoch + early stopping

伪代码概念：

```python
for step, batch in enumerate(loader):
    loss = model(batch)
    loss.backward()
    clip_grad_norm_(model.parameters(), 1.0)
    optimizer.step(); optimizer.zero_grad()
    scheduler.step()
```

## 面试取舍

面试常见坑：只会背 Adam 公式，说不清「微调为何要小 lr」。更好的回答：预训练特征已有用，大步长会破坏表示；应用层用小 lr 或适配器。

取舍：Adam 收敛快、调参省心；强基线对比时保留 SGD+动量选项。

## FDE用法

1. 客户要「再训一下」时，先问数据量、是否可验证、能否回滚权重。
2. 把 lr、batch、epoch、种子写入训练配置与 MLflow/W&B 一类记录。
3. 生产续训必须保留旧模型影子对比，防灾难性遗忘。

## 易混点

围绕「梯度下降与学习率」，现场最常见的概念混淆：

1. **把代理指标当成业务结果**：技术分上涨不等于采纳、周期或风险下降。
2. **只看平均、不看切片**：整体健康时，高风险长尾可能已经崩盘。
3. **同时改多个旋钮**：无法归因，复盘只能靠叙事。
4. **忽略标注/量规版本**：指标不可比，却被讲成「模型变强」。
5. **缺乏回滚故事**：说得清正向收益，说不清如何止损。
