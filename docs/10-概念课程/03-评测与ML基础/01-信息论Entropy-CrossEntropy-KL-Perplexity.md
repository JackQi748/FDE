# 信息论：Entropy / Cross-Entropy / KL / Perplexity

## 直觉

把模型输出想成「对下一事件的赌局」。**熵（Entropy）**描述真实分布有多不确定；**交叉熵（Cross-Entropy）**描述你用模型分布去编码真实事件要付多少「码长」；**KL 散度**是交叉熵减去熵，衡量「模型相对真相多浪费了多少」；**困惑度（Perplexity）**把交叉熵指数化，读起来像「模型平均在多少选项之间犹豫」。

直觉口诀：熵是真相的难度；交叉熵是你答题的代价；KL 是多余代价；困惑度是「等效分支数」。

## 讲解

### 符号与关系

对离散分布 \(p\)（真相）与 \(q\)（模型）：

- \(H(p) = -\sum_i p_i \log p_i\)
- \(H(p,q) = -\sum_i p_i \log q_i\)（交叉熵）
- \(D_{KL}(p\|q) = H(p,q) - H(p) \ge 0\)
- \(\mathrm{PPL}(q) = \exp(H_{\text{avg}})\)，语言模型里常用每 token 平均负对数似然的指数

训练分类器时，标签常近似 one-hot，于是最小化交叉熵 ≈ 推高正确类的对数概率。生成模型同理：在语料上最小化负对数似然。

### 为什么工程上几乎只谈交叉熵

真分布 \(p\) 未知或在小样本上噪声很大，\(H(p)\) 常数不影响梯度方向；优化器实际最小化的是交叉熵估计。KL 更适合做「两个已知分布」的比较、蒸馏、变分推断里的正则项。

### 困惑度的可读性与陷阱

困惑度下降通常意味着模型更「会猜」下一 token，但不等于业务正确。分词器不同、文本域不同、大小写/空白规范化不同，都会让 PPL 不可横向比较。开放生成质量更依赖任务指标与人类/裁判量规。

| 量 | 问的问题 | 常见误用 |
|----|----------|----------|
| Entropy | 标签本身有多乱 | 当成模型好坏 |
| CE | 模型对真标签罚多重 | 与准确率一一对应 |
| KL | 两分布差多少 | 忽略方向性 \(p\|q\) vs \(q\|p\) |
| PPL | 等效犹豫宽度 | 跨模型/跨域横比 |

## 工作示例

场景：客服意图分类，三类意图先验接近均匀，\(H(p)\approx \log 3\)。基线模型在验证集平均交叉熵 0.55 nat，困惑度约 \(e^{0.55}\approx 1.73\)——可理解为「平均在不到 2 个选项间犹豫」。

上线后业务加了稀有意图「投诉升级」，该类样本少但代价高。整体 CE 几乎不动，但该类条件 CE 很高。正确做法是分层报告：整体 CE/PPL + 每意图 CE + 业务代价加权错误，而不是只盯一个困惑度。

伪代码（概念）：

```python
# y: one-hot or class index; log_probs: model log q(y|x)
ce = -log_probs[range(n), y].mean()
ppl = ce.exp()  # 若 ce 以 nat 计
```

蒸馏时：用 \(D_{KL}(p_{\text{teacher}}\|q_{\text{student}})\) 让学生贴近教师软标签，温度 \(T\) 放大暗知识。

## 面试取舍

| 选择 | 何时倾向 | 代价 |
|------|----------|------|
| 报 CE/PPL | 预训练/续训健康检查 | 不直接等于业务分 |
| 报任务指标 | 交付验收 | 需要金标与量规 |
| 用 KL 做约束 | 蒸馏、防止崩分布 | 实现与温度敏感 |

面试宜说清：**PPL 是训练能量表，不是客户 KPI**；同时能手推 CE 与 KL 关系，避免把「熵」和「交叉熵」混称。

## FDE用法

1. 微调前后在**同一分词器、同一验证切片**上记录 CE/PPL，作为「模型是否还记得语言」的烟测。
2. 与业务指标并排看板：PPL 降但拒答率升，可能是过度保守。
3. 向客户解释时用「犹豫宽度」类比，再落到精确率/召回或采纳率。
4. RAG/Agent 项目不要用语料 PPL 替代端到端 eval。

## 易混点

围绕「信息论：Entropy / Cross-Entropy / KL / Perplexity」，现场最常见的概念混淆：

1. **把代理指标当成业务结果**：技术分上涨不等于采纳、周期或风险下降。
2. **只看平均、不看切片**：整体健康时，高风险长尾可能已经崩盘。
3. **同时改多个旋钮**：无法归因，复盘只能靠叙事。
4. **忽略标注/量规版本**：指标不可比，却被讲成「模型变强」。
5. **缺乏回滚故事**：说得清正向收益，说不清如何止损。
