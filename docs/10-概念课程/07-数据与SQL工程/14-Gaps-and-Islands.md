# Gaps and Islands（缺口与岛屿）

一句话直觉：把有序数据里的「连续段」收成一段段岛屿、把中间空洞标成缺口——窗口函数是手术刀，业务定义是刀谱。

## 直觉讲解

**Islands（岛屿）**：在序列上连续满足某条件的最大区段。例如：设备连续在线的时间段；用户连续活跃日；订单状态保持「处理中」的区间。

**Gaps（缺口）**：岛屿之间的空洞。例如：库存连续缺货的间隙；SLA 监控中无心跳的时段。

经典 SQL 套路（「值 − 行号」构造岛键）：

1. 滤出目标行（如状态=在线）  
2. 按实体分区、按时间排序，打 `ROW_NUMBER`  
3. 用「日期 − rn 天」或「序号差」生成 `island_id`  
4. 按 `island_id` 聚合得起止  

也可用 `LAG` 检测与上一行是否断裂，断裂则开新岛。

```mermaid
flowchart LR
  Seq[有序事件] --> Flag[标记目标行]
  Flag --> Brk[LAG 检测断裂]
  Brk --> Isl[分配 island_id]
  Isl --> Agg[聚合起止与时长]
```

与 SCD2 生效区间、会话化（sessionization）、运维可用性计算同源：都是在时间轴上切段。FDE 常见于：设备 IoT、会员连续订阅、Agent 会话切割、数据新鲜度空洞检测。

## 工作示例（数字/场景）

**场景 A：连续活跃日岛屿**

用户活跃日期：1,2,3,5,6,9  

| 岛 | 起 | 止 | 长 |
|----|----|----|----|
| 1 | 1 | 3 | 3 |
| 2 | 5 | 6 | 2 |
| 3 | 9 | 9 | 1 |

缺口：3→5、6→9。

```sql
-- 示意：按日活跃构造岛
WITH days AS (
  SELECT user_id, dt,
         ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY dt) AS rn
  FROM user_active_days
),
marked AS (
  SELECT user_id, dt,
         dt - (rn || ' days')::interval AS island_key  -- 方言示意
  FROM days
)
SELECT user_id, island_key,
       MIN(dt) AS start_dt, MAX(dt) AS end_dt,
       COUNT(*) AS streak_days
FROM marked
GROUP BY 1, 2;
```

（不同引擎日期算术不同，思想相同：有序位置与时间对齐差分。）

**场景 B：数据管道新鲜度缺口**

小时分区应连续。用岛屿找「连续缺失小时」最长段，告警「源停摆」而非单点失败。

**场景 C：Agent 会话**

事件流按 `user_id` 排序；若与上条间隔 > 30 分钟则新会话——这是 `LAG` 断裂法的会话化，本质 Gaps/Islands。

| 陷阱 | 处理 |
|------|------|
| 时区混用 | 统一 UTC |
| 重复时间戳 | 加稳定次序 |
| 营业日 vs 自然日 | 用日历表定义「连续」 |
| 状态来回抖 | 先平滑/合并短间隙 |

## 面试常问取舍

1. **SQL 岛屿 vs 应用层扫一遍？**  
   - 千万行级在仓内 SQL/Spark 更合适；小结果可应用层。  

2. **短间隙要不要合并进岛？**  
   - 产品问题：心跳漏 1 分钟算掉线吗？定义容错窗口。  

3. **与窗口滑动统计区别？**  
   - 滑动统计回答「附近均值」；岛屿回答「连续段边界」。常组合用。  

4. **递归 CTE？**  
   - 某些缺口问题可用递归；性能与可读性通常不如窗口岛键法。

## FDE 现场怎么用

1. 先用自然语言写清「连续」定义（自然日/工作日/含容错）。  
2. 用小样例表（10 行）固化期望岛屿，再写 SQL。  
3. 监控类：缺口长度进 SLA 仪表盘。  
4. AI：会话切割与「连续失败工具调用」段可用于轨迹评测特征。  
5. 口条：「岛屿是压缩后的时间真相，缺口是事故的形状。」

## 深入：容错间隙与性能

### 合并短间隙
监控心跳允许 2 分钟丢包仍算同一岛屿：先扩「在线」定义或后处理合并间隙 < τ 的岛。τ 要产品签字。

### 大数据性能
岛键法通常单次排序；注意分区键倾斜（超大用户）。可先按日预聚合再岛化。

### 与 SCD2
SCD2 区间本身是岛屿的特化。缺口检测可找维表「无当前行」的时间段——主数据空洞。

### 测试夹具
固定 10 行事件 + 期望岛表，作为 SQL 单元测试。比在生产对数更高效。

### 课堂小结
Gaps/Islands 把窗口函数从「取最新」升级到「时间形态学」；定义清，SQL 才有意义。
