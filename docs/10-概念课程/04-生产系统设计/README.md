# 04 · 生产系统设计

面向 FDE 的生产化概念轨道：把能演示的 AI 系统，变成可观测、可限流、可降级、可审计、算得过账的线上系统。原创中文，强调取舍与现场动作；可与 `docs/02`、`docs/03`、`docs/05` 交叉阅读。

## 怎么读

1. 先读 **01 从POC到生产**、**19 企业AI参考架构**、**18 部署模型**——定地图。
2. 硬化手段一组：**03 重试**、**04 幂等**、**05 限流**、**09 熔断背压**、**16 降级转移**。
3. 运营一组：**06 可观测性**、**07 延迟**、**02 成本**、**20 SLO/错误预算**。
4. 集成与交付：**11 Walking Skeleton**、**12 REST**、**13 容器K8s**、**15 消息队列**、**14 CAP与工作流**。
5. 平台语境：**08 VPC气隙**、**10 Ontology**、**17 Palantir平台**。
