# 05 · MLOps 与生命周期

面向 FDE 的 MLOps 概念轨道：从漂移监测、模型注册晋级、CI/CD、监控、特征治理，到供应商换代与 Eval 门禁。原创中文，强调可值班、可回滚、可审计；与 `docs/03-AI落地`、`docs/04-生产系统设计`、`docs/03-评测与ML基础` 交叉阅读。

## 怎么读

1. **问题从哪来**：先读 **01 漂移**、**04 监控**——知道线上如何变坏。  
2. **变更如何受控**：**02 注册晋级** → **03 模型 CI/CD** → **07 Eval 门禁**。  
3. **数据面**：**05 特征商店**（防训练-服务倾斜）。  
4. **外部冲击**：**06 模型版本与迁移**（供应商换代剧本）。
