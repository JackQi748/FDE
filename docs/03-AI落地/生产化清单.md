# 生产化清单

把试点变成可运营系统时，用本清单做工程就绪与 Go/No-Go。  
对照：[生产 Go-Live 清单](../08-工具箱与清单/生产Go-Live清单.md)（会议勾选）、[变更管理](../05-能力补强/变更管理与培训设计.md)、[评测](./评测Eval与Guardrails.md)。

---

## 0. 怎么用这份清单

1. 工程侧提前逐项勾完，附证据链接  
2. 会上只看红灯与决策  
3. 「有条件通过」必须有负责人与到期日  

---

## 1. 可靠性

- [ ] 超时、重试、降级路径明确（仅检索 / 转人工 / 只读）  
- [ ] 幂等与去重（Webhook、工具写操作）  
- [ ] 依赖健康检查（模型 API、向量库、内部 API）  
- [ ] 限流与配额（按租户/用户）  
- [ ] 回滚方案（配置、提示词、索引版本可回退）  
- [ ] 演练过至少一次回滚或降级（记录时间）  
- [ ] 单点依赖有说明（无 HA 也要诚实写出）  

**证据**：架构图、演练纪要、配置仓库 tag。

---

## 2. 观测与运营

- [ ] 结构化日志（request_id、user、工具轨迹摘要）  
- [ ] 追踪（关键跨服务）  
- [ ] 看板：延迟、成本、错误、采纳率/任务完成率  
- [ ] 告警路由到真实值班人（不是废弃邮箱）  
- [ ] Runbook：≥5 条常见故障  
- [ ] 反馈入口（点踩/上报）进入 backlog 与 Eval  
- [ ] on-call 与升级路径客户侧知情  

---

## 3. 安全与合规

- [ ] SSO/身份集成完成  
- [ ] 文档/行级权限在检索与工具层强制  
- [ ] 密钥：KMS/密管，无硬编码、无进 Git 史  
- [ ] PII：脱敏、保留期、访问控制  
- [ ] 驻留与出站路径符合合同  
- [ ] 审计：谁问了什么、调了何工具、谁批准  
- [ ] 提示注入与越权红队用例通过  
- [ ] 模型商/subprocessors 条款已审  
- [ ] 缓存不串用户/租户  

详见 [SSO](../05-能力补强/企业SSO与权限模型.md)、[网络白话](../05-能力补强/企业网络与私有连接白话.md)。

---

## 4. 成本与延迟

- [ ] 单次请求成本估算与预算告警  
- [ ] 模型分级（简单查询走小模型/缓存）  
- [ ] 检索 top-k 与上下文长度上限  
- [ ] 安全前提下的缓存策略  
- [ ] SLA：P95 延迟已在目标环境测过（非笔记本）  
- [ ] 峰值流量假设与限流行为对用户可见  

---

## 5. 质量与评测

- [ ] 冻结黄金集与通过线  
- [ ] 发版跑回归；失败可阻断  
- [ ] 已知弱点书面化（如表格差）  
- [ ] 高危路径有 HITL  

见 [Eval](./评测Eval与Guardrails.md)、[评测双环](./LLM评测双环.md)。

---

## 6. 变更管理（工程侧）

- [ ] 提示词/编排版本化  
- [ ] 索引重建流程文档化  
- [ ] 高危工具开关需评审  
- [ ] Eval 回归是合并门槛  
- [ ] 变更窗口与沟通口径准备好  

---

## 7. 用户与交接

- [ ] 培训完成，录屏/速查可查  
- [ ] 客户侧产品/技术 owner 指名  
- [ ] 支持渠道与升级路径  
- [ ] 已知限制对用户可见（诚实 UX）  
- [ ] Day-2：谁值班、谁改提示、谁批工具  

见 [变更管理与培训](../05-能力补强/变更管理与培训设计.md)。

---

## 8. Go/No-Go 会议议程（45 分钟）

| 分钟 | 内容 |
|------|------|
| 10 | 指标相对基线 |
| 10 | 开放风险与安全结论 |
| 10 | 运营就绪（观测/值班/Runbook） |
| 10 | 决策：上线 / 有条件 / 延期 |
| 5 | 对外沟通口径 |

输出必须是**书面决策**，不是「大家觉得可以」。

---

## 9. 上线后 14 天

| 动作 | 频率 |
|------|------|
| 失败案例回顾 | 每日（首周） |
| 成本与延迟曲线 | 每日看，周总结 |
| 用户访谈 | ≥5 人 |
| 决定扩/停/改 | Day 14 Review |

然后进入 [Review](../02-交付方法论/Discover-Design-Deploy-Review.md)。
